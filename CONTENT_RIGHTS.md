# Content rights

This project shows pictures that other people made. Two different things are
covered here, and they must not be confused.

## 1. The source code

The website, the data pipeline, the JSON API tooling and the Android app in
this repository are open source under the MIT licence in [`LICENSE`](LICENSE).
You may use, modify and redistribute that code.

## 2. The pictures, videos and texts

The Astronomy Picture of the Day entries published by this project are **not**
covered by the MIT licence.

* Each entry is the work of its own creator. Many are photographs or
  illustrations that were made specifically for NASA APOD; others come from
  observatories, professional studios, amateur astronomers and space agencies.
* APOD states that "specific rights apply" to each entry. Some are released
  into the public domain, some are made available for editorial and educational
  use with a credit, and some are copyrighted by their creators.
* **The collection as a whole is not public domain.** Do not describe the
  archive, the API or the app as "free images" or "public domain images".

### What this project does

* Keeps the credit exactly as it was supplied by the source, and never removes
  it.
* Links every entry to the original APOD page and to the original image file.
* Publishes only metadata and links. **No image binaries are mirrored into this
  repository or into the published API** — the pictures stay on NASA's own
  servers.
* Keeps the credit attached when an entry is saved from the Android app or
  shared through the system share sheet.

### What you should do if you reuse an entry

1. Open the entry's "Original APOD page" link and read the credit and the
   rights statement there.
2. Credit the creator exactly as shown, and link back to the APOD page.
3. Ask the creator if the intended use is not covered by the entry's terms.

The source of the data is NASA's public APOD service. NASA does not endorse
this project or the way its entries are displayed.

## 4. Reporting a problem

If a credit is missing, wrong, or a link points somewhere it should not, or
if an entry is displayed in a way that breaks its rights, please
[open an issue](https://github.com/hello2himel/mohakash/issues). Wrong
attribution is treated as a bug.
